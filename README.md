# 栖云 Qiyun

用自然语言照看你的服务器。

一个计划中的自托管 AI 运维工作台：在 Web 中用文字或语音查看 Linux 云服务器、理解故障，并完成有明确范围、可验证、可追溯的日常操作。

**当前状态：项目定义阶段。尚无可运行应用、真实服务器连接、模型调用或可用安装命令。**

工作名称暂定“栖云 Qiyun”，尚未进行商标、域名及开源项目重名核查。本文描述的产品能力均为建设目标。

## 已确定的方向

- 首批用户：独立开发者和管理少量 VPS 的小团队。
- 首批对象：Linux 云服务器、Docker Compose 网站、常见 systemd 服务。
- 交互方式：服务工作台 + 自然语言任务 + 语音转文字。
- 执行流程：观察 → 计划 → 按策略确认 → 执行 → 健康验证 → 留下记录。
- 模型方向：火山方舟 Ark + DeepSeek V4.1 Flash；运行时接入条件见下方文档。
- 分发方向：自托管、一行命令启动安装、版本化升级。
- 视觉方向：温暖浅色、精致深色、清晰状态、轻盈动效，避免监控大屏式堆砌。

## 下一步工程切片

先制作服务总览、服务详情和任务执行三条核心交互，再打通一台测试 Linux 主机的只读采集。随后完成一次受控服务重启的真实闭环，最后扩展配置更新、语音和安装发行。

应用源码和受管服务器配置使用相互独立的 Git 仓库。密钥、日志、数据库和备份均不进入源码仓库。现在只使用本地 Git；远程仓库和发布地址尚未配置。
