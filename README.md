# 栖云 Qiyun

用自然语言照看你的服务器。

一个自托管 AI 运维工作台，面向 Linux 云服务器 / VPS 上的 Docker 容器与已登记 systemd 服务。在 Web 中查看运行状态、读取日志、发起检查，并在确认具体方案后重启指定服务。

**当前状态：首版工程已实现，核心链路验收通过。可运行工作台、隔离演示环境、控制端和 Linux Agent 已存在；尚不是生产就绪发行版。**

工作名称暂定“栖云 Qiyun”，尚未进行商标、域名及开源项目重名核查。

## 当前可以做什么

- **查看资源：** 服务器 CPU、内存、磁盘、连接状态与近期采样；已登记 Docker / systemd 服务的运行状态与有界日志。未采集的指标显示不可用。
- **自然语言检查：** 使用服务端配置的 Ark Coding Plan / DeepSeek，调用限定范围内的资产与日志工具，展示结论和任务证据。
- **受控重启：** 自然语言建议和手动按钮走同一计划、审批、版本检查与执行路径。重启后核对容器 / systemd 状态，不把进程运行等同于网站业务正常。
- **追溯任务：** 查看操作过程、待确认方案、失败或结果未知状态。Agent 与 helper 保存执行收据，避免盲目重复重启。
- **文字与语音：** 浏览器支持时可语音转写，编辑后再提交；不支持或识别失败时保留文字入口。独立 ASR 尚未接入。
- **自托管体验：** 单管理员初始化与登录、浅色 / 深色外观、窄屏布局、减少动态效果、配对令牌。演示会话使用明确标记的模拟数据，不连接真实主机、不调用模型。

当前不提供网站主动 HTTP / TLS 检测、任意 Shell、Compose 配置部署、镜像更新、配置 / 数据回滚、定时巡检或无人值守自动修复。完整范围见[项目状态与路线图](docs/PROJECT.md)。

## 本地运行

需要 Node.js **24.15+** 与 pnpm **11.25.0**。在完整源码目录中：

```sh
pnpm install --frozen-lockfile
cp .env.example .env
pnpm run dev
```

Windows PowerShell 使用 `Copy-Item .env.example .env`。打开 `http://127.0.0.1:5173`，首次设置管理员，或先进入演示工作台。

控制端默认端口为 **4310**，主机 HTTPS 通道为 **4311**。若端口被占用，可通过 `.env` 调整；开发启动脚本会将 Web API 代理指向配置的控制端端口。模型密钥仅由服务端环境变量或秘密文件读取，不放入浏览器变量。

构建、端口配置、模型接入、Linux 主机配对和权限白名单见[运行与接入](docs/RUNNING.md)。

已经取得源码且安装 Docker Engine / Compose v2 的 Linux 主机，可在仓库根目录执行：

```sh
sh deploy/install.sh
```

该命令从本地源码构建并启动控制端。管理员初始化、CA 信任、Agent 安装和 helper 白名单仍按运行文档单独配置；当前没有公共下载 URL、签名发行包或自动升级流程。

- 16 项 TypeScript 测试通过；Go 测试及 `go vet` 通过，Linux 环境的 16 组 Go 测试通过。
- 指定 Ark 端点完成一次简单连通性探测和一次流式工具调用冒烟。后者包含 2 次模型请求，输入 1,309 / 输出 90 tokens；读取样例资产后完成中文回复，不连接真实服务器。
- 真实 Linux Docker 端到端验收通过：一次性注册与 mTLS、真实容器发现和日志、批准前无动作、签名重启与后置验证、重复批准不重复重启；隔离测试资源已清理。
- 真实 Ark 自然语言到 Linux 执行的全链路也已通过：3 次模型请求形成结构化方案，批准后完成隔离容器重启与结果验证。
- 控制端 Docker 镜像实际构建、普通用户运行、首页与 API、健康检查和管理员初始化通过。
- 浏览器 19 项流程自动检查通过；截图验收发现的暗色继承色问题已修复，桌面、深色、任务方案与手机截图复核已完成。尚不宣称完整兼容性或无障碍验收通过。
